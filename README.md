# OBRASIA — Construction AI

Plataforma de inteligência artificial para engenharia civil e gestão de obras.

## Funcionalidades
- Planejamento de obras
- Simulação de cronogramas
- Otimização de custos
- Gestão de equipes e equipamentos
- Comparação de cenários
- Dashboard de engenharia

## Tecnologia
Python, FastAPI e JavaScript.

Em desenvolvimento.
